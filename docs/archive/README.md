# Archived interim reports

These reports were written in October 2026, before every model had been evaluated on every split with the final
evaluation harness. They are kept for the record but are superseded. The final numbers are in
[results/tables/main_table.md](../../results/tables/main_table.md), generated by `python -m analysis.main_table` from
`results/eval/`, and [notebooks/project.ipynb](../../notebooks/project.ipynb) reproduces them.

Claims in these reports that the final evaluation corrects:

- **"Model C is best on unseen paths (0.109 vs 0.173)".** This compared C, trained with rotation and reflection
  augmentation, with Model A trained without it. With the same augmentation A scores 0.099 on test_path, and B (0.077)
  and D (0.012) are both better than C.
- **Validation melting-range MAE and IoU of B and D.** The three-seed means are 3.71 K / 0.977 (B) and 6.29 K / 0.982
  (D), not 3.38 K / 0.988 and 4.85 K / 0.980.
- **Parameter counts.** The GCN has 318,593 trainable parameters (not about 215,000) and Model D 2,365,058 (not
  2,332,161).
- **"Model D: 0.000000 J energy error".** This holds for the energy on D's own mesh, which D conserves exactly. Against
  the solver, D's final energy error is -0.20% on val and -0.14% on test_path: the offset that interpolating the
  solver data onto the mesh introduces.
- **"About 49x speed-up".** This compared the solver on one CPU core with a model on an A100 GPU. On one 12-core CPU,
  the solver takes 3.3 s for the zigzag test run and the GNN rollouts 11-45 s (`notebooks/project.ipynb`).

Links to `file:///scratch/...` paths in these reports point to a cluster account and do not work outside it.
